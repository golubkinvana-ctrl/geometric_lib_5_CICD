# Geometric Lib

## Общее описание решения
Библиотека `Geometric Lib` является набором функций для вычисления площади и периметра геометрических фигур: круга, квадрата, прямоугольника и треугольника. Проект написан на языке Python, вычисления происходят через самые простые формулы известной геометрии.


### Описание функций

## square.py
*   **area(a)** — принимает сторону `a`, возвращает площадь квадрата.
    *   Пример: `area(3)` ---> `9`
*   **perimeter(a)** — принимает сторону `a`, возвращает периметр квадрата.
    *   Пример: `perimeter(3)` ---> `12`

## rectangle.py
*   **area(a, b)** — принимает стороны `a` и `b`, возвращает площадь прямоугольника.
    *   Пример: `area(3, 4)` ---> `12`
*   **perimeter(a, b)** — принимает стороны `a` и `b`, возвращает периметр прямоугольника.
    *   Пример: `perimeter(3, 4)` ---> `14`

## circle.py
*   **area(r)** — принимает радиус `r`, возвращает площадь круга данного радиуса.
    *   Пример: `area(5)` ---> `78.53981633974483`
*   **perimeter(r)** — принимает радиус `r`, возвращает длину окружности данного радиуса.
    *   Пример: `perimeter(5)` ---> `31.41592653589793`

## triangle.py
*   **area(a, h)** — принимает сторону `a` и высоту `h`, возвращает площадь треугольника.
    *   Пример: `area(4, 5)` ---> `10.0`
*   **perimeter(a, b, c)** — принимает стороны `a`, `b`, `c`, возвращает периметр треугольника.
    *   Пример: `perimeter(3, 4, 6)` ---> `13`
